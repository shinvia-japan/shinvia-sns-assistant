# Shinvia SNS投稿アシスタント

Instagram・Threads・楽天ROOM向けの投稿文案を作成する、日本語の無料試作品です。青と白の画面で、テーマ入力 → 文案作成 → 編集 → 保存・コピーができます。

## 初めての起動

1. [Node.js](https://nodejs.org/ja) のLTS版（Node.js 20以上）をインストールします。
2. GitHubの「Code」→「Download ZIP」でダウンロードして展開するか、次のコマンドで取得します。
   ```sh
   git clone https://github.com/shinvia-japan/shinvia-sns-assistant.git
   cd shinvia-sns-assistant
   ```
3. 展開した `shinvia-sns-assistant` フォルダでターミナルを開き、次を実行します。
   ```sh
   npm start
   ```
   追加パッケージのインストールやAPIキーは不要です。
4. ブラウザのアドレス欄に `http://localhost:3000` を入力します。
5. 終了するときはターミナルで `Ctrl+C` を押します。次回も同じフォルダで `npm start` を実行します。

「node / npm が見つからない」場合はNode.jsをインストールし、ターミナルを開き直してください。ポートが使用中の場合は既存のサーバーを終了するか、macOS/Linuxでは `PORT=3001 npm start`、PowerShellでは `$env:PORT=3001; npm start` を使い、3001番のURLを開いてください。

## 使い方

1. 投稿先のSNSを選びます。
2. 投稿テーマを入力します。「試してみる」の例も使えます。
3. 必要なら伝えたいポイントと文章の雰囲気を指定します。
4. 「投稿文案を作成する」を押し、右側（スマートフォンでは下側）の文章を編集します。
5. 「保存する」でこのブラウザに保存します。「保存した投稿」から開き直して上書きできます。
6. 「コピーする」を押してSNSの投稿画面に貼り付けます。自動コピーが使えない場合は選択された文章を手動コピーしてください。

## 試作品の範囲

- 外部AIや外部APIへの通信は行いません。AI投稿作成の操作を体験するため、媒体別のテンプレートに入力内容を組み合わせます。自由な推論や事実確認は行いません。
- 楽天ROOMでは商品取得や価格確認をしません。実際の体験、商品情報、広告・PRの表示などは投稿前に自身で確認してください。
- 保存はブラウザのlocalStorageです。アカウント、クラウド同期、画像アップロード、SNSへの自動投稿はありません。
- 保存内容は端末・ブラウザ・接続先URLごとに異なります。ブラウザデータ削除やプライベートモード終了で失われる場合があります。大切な文章は別途保管してください。機密情報の保存は避けてください。
- 公開運用用の認証・バックアップは未実装です。開発サーバーは初期設定で端末内からのみアクセスできます。

## 開発と確認

```sh
npm test
npm start
```

`npm test` は投稿先ごとの文案、テーマの検証、保存データの読み取りを確認します。画面では、3媒体での作成・編集・保存・再読み込み・コピー・削除を確認してください。

構成：`index.html`（画面）、`style.css`（見た目）、`app.js`（操作・保存）、`generator.js`（文案）、`server.js`（開発サーバー）。依存パッケージはありません。

## GitHubへの保存

Web画面の「保存する」は投稿文のブラウザ保存であり、GitHubへの保存ではありません。コードを変更したら、リポジトリのフォルダで以下を実行します。

```sh
git switch -c feature/my-change
git add .
git commit -m "Update Shinvia SNS assistant"
git push -u origin feature/my-change
```

GitHubの画面でPull Requestを作成し、確認後にmainへ取り込みます。pushにはリポジトリの書き込み権限が必要です。認証情報をコードに書かないでください。
